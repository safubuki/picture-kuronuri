# KuroNuri Studio (プライバシー墨消しカメラ)

> **100% 端末内処理・外部送信ゼロ（完全オフライン対応）**  
> スマホやPCで撮影・選択した画像から、人の顔・アバター・人名・会社名・連絡先を自動検出して安全に墨消し（黒塗り）するWebアプリケーションです。手で黒塗りを足したり、矢印や囲みで注釈を入れたりもできます。

---

## 🌟 特長

1. **端末内で処理・画像とテキストの外部送信ゼロ**
   - 画像データや検出されたテキストは外部サーバーや外部AIクラウドへ一切送信されません。
   - ブラウザ内部（WebAssembly / Canvas API）で処理します。初回の解析時だけOCR言語データ（日本語・英語、約5MB）を取得します。ブラウザに保存した後はオフラインで利用でき、保存状況は設定画面で確認・削除できます。
   - ホーム画面に追加してアプリとして使えます（PWA）。

2. **チャット画面・書類に特化した自動黒塗り**
   - **人の顔・写真アイコン**: ネイティブ顔検出と写真の色階調・肌・背景分離から人物写真を推定。イニシャル・単色の操作アイコンは残し、OCR本文との重なりも確認します。
   - **人名・敬称**: ローカル姓辞書＋敬称・氏名ラベル・送信者配置を解析。挨拶・一般の見出し・地名への部分一致を抑え、文書内の同名だけを伝播します。
   - **会社名・法人**: 株式会社、有限会社、合同会社、および文脈パターンを検出。
   - **連絡先・PII**: メールアドレス、電話番号、郵便番号、住所表記などを自動マスキング。

3. **手で引く黒塗り（✍️ 黒塗追加）**
   - 文字を横になぞるだけで、検出した文字行に合わせて黒塗りを引きます（行スナップ）。同じ行で重なる線は1本にまとめます。
   - 長押しで四角く囲む黒塗りに切り替わり、アイコンや写真も隠せます。
   - 黒塗りの両端の丸をドラッグすると長さを調整できます。縦にさっと動かすとスクロールです。

4. **黒塗りの編集と一括設定（👆 選択/移動）**
   - 黒塗りを押すと編集パネルが開き、項目（メール・人名・電話・パスワード・住所・会社名・金額・ファイルパス・手動・自由入力・文字なし）、線の太さ・位置、ラベルの文字サイズを変えられます。保護の一時解除と削除もここから行えます。
   - **まとめて選択**: `Ctrl`（Mac は `⌘`）または `Shift` を押しながらクリックで選択に追加・解除、押しながらドラッグで範囲選択、`Ctrl + A` で全選択。選んだ黒塗りすべてに同じ設定を一度に反映し、「戻す」1回で元に戻せます。
   - 項目がバラバラな黒塗りをまとめて選んだときは、項目を選び直さない限り各黒塗りの項目名をそのまま残します（太さだけ揃える、といった使い方ができます）。
   - パネルの「同じ項目の黒塗りをすべて選択」で、同じ項目名の黒塗りをまとめて選べます（スマホでも一括設定できます）。

5. **図形で注釈（🖍️ 図形）**
   - 矢印・丸・四角を、6色（赤・黄・緑・青・白・黒）と3段階の太さで描けます。矢印はドラッグを終えた側が矢じりです。
   - 描いた図形の線を押すと選択でき、ドラッグで移動、色・種類・太さの変更、削除（`Delete` キー）ができます。
   - 図形は黒塗りの上に重ねて描かれ、画像のコピー・保存にも含まれます。

6. **斜め撮影写真の自動補正（AI不使用の数学的画像処理）**
   - **⚡ 自動フラット化＆解析**: スマホの斜め撮影による台形歪み・傾きをSobelエッジ検出＋極値凸包探索＋ホモグラフィ透視変換で自動正面補正。
   - **📐 4隅調整**: 4隅のピンを虫眼鏡で微調整して正面に補正します。
   - **傾き追従マスキング**: 元写真の構図を保ったまま、斜めのテキスト行に合わせて傾いた黒塗りとラベルを配置。

7. **インラインラベルと表現スタイル**
   - 黒塗りボックスの**同一行内**に「人名」「会社名」などのカテゴリを表示。上の行や下の行の文章を潰さず、前後の文脈を保持したままAI相談等に活用できます。ラベルを入れず黒塗りだけにすることもできます。
   - 表現は漆黒塗り・白塗り・モザイク・ぼかしから選べます。「元画像」で補正前と見比べられます。
   - 「戻す」「進む」は黒塗りと図形で共通です。

8. **柔軟なエクスポート**
   - ワンクリックでクリップボードに画像をコピー（ChatGPTやClaudeにそのまま貼付可能）、またはPNGで保存。
   - 黒塗り箇所を `[人名]` `[住所]` などに置き換えた伏字テキストと、AI相談用の定型プロンプト（要約依頼、決定事項整理、返信案作成など）をワンクリックコピー。

## ⌨️ PCでのショートカット

| 操作 | 内容 |
| --- | --- |
| `Ctrl` / `Shift` + クリック | 黒塗りを選択に追加・解除（選択/移動モード） |
| `Ctrl` / `Shift` + ドラッグ | 囲んだ黒塗りをまとめて選択（選択/移動モード） |
| `Ctrl + A` | すべての黒塗りを選択（選択/移動モード） |
| `Esc` | 選択を解除して編集パネルを閉じる |
| `Delete` / `Backspace` | 選んでいる図形を削除（図形モード） |
| `Space` + ドラッグ、中ボタンドラッグ | 画面の移動 |

Mac では `Ctrl` の代わりに `⌘` も使えます。

## 🛠️ 技術スタック

- **フロントエンド**: TypeScript, HTML5 Canvas, Vanilla CSS
- **OCR・文字認識**: Tesseract.js (クライアントサイド WebAssembly)
- **アイコン**: Lucide Icons
- **ビルドツール**: Vite（vite-plugin-pwa）
- **画像の個人情報判定**: 正規表現・辞書・チェックディジット・帳票レイアウト規則

## 🚀 ローカル起動方法

```bash
# 依存パッケージのインストール
npm install

# 開発サーバー起動
npm run dev

# 本番用ビルド
npm run build
```
