# KuroNuri Studio (プライバシー墨消しカメラ)

> **100% 端末内処理・外部送信ゼロ（完全オフライン対応）**  
> スマホやPCで撮影・選択した画像から、人の顔・アバター・人名・会社名・連絡先を自動検出して安全に墨消し（黒塗り）するWebアプリケーションです。

---

## 🌟 特長

1. **端末内で処理・画像とテキストの外部送信ゼロ**
   - 画像データや検出されたテキストは外部サーバーや外部AIクラウドへ一切送信されません。
   - ブラウザ内部（WebAssembly / WebGPU / Canvas API）で処理します。初回のOCRデータ・任意のLLMモデル取得には通信が必要で、保存後はオフラインで利用できます。

2. **チャット画面・書類に特化した自動黒塗り**
   - **人の顔・写真アイコン**: ネイティブ顔検出と写真の色階調・肌・背景分離から人物写真を推定。イニシャル・単色の操作アイコンは残し、OCR本文との重なりも確認します。
   - **人名・敬称**: ローカル姓辞書＋敬称・氏名ラベル・送信者配置を解析。挨拶・一般の見出し・地名への部分一致を抑え、文書内の同名だけを伝播します。
   - **会社名・法人**: 株式会社、有限会社、合同会社、および文脈パターンを検出。
   - **連絡先・PII**: メールアドレス、電話番号、郵便番号、住所表記などを自動マスキング。

3. **斜め撮影写真の自動補正（AI不使用の数学的画像処理）**
   - **⚡ 自動フラット化＆解析**: スマホの斜め撮影による台形歪み・傾きをSobelエッジ検出＋極値凸包探索＋ホモグラフィ透視変換で自動正面補正。
   - **📐 傾き追従マスキング**: 元写真の構図を保ったまま、斜めのテキスト行に合わせて傾いた黒塗りとラベルを配置。

4. **インラインラベル表示**
   - 黒塗りボックスの**同一行内**に「人名」「会社名」などのカテゴリを表示。上の行や下の行の文章を潰さず、前後の文脈を保持したままAI相談等に活用できます。

5. **柔軟なエクスポート**
   - ワンクリックでクリップボードに画像をコピー（ChatGPTやClaudeにそのまま貼付可能）。
   - AI相談用の定型プロンプト（要約依頼、決定事項整理、返信案作成など）をワンクリックコピー。

6. **任意のAI文章清書・伏字化**
   - オプトインで **Qwen3 0.6B** を端末内で実行。思考モードをOFFにして、OCRテキストの清書・追加の伏字化に使用します。
   - 初回ダウンロードは、対応WebGPUで約600MB（`q4f16`）、それ以外で約950MB（`q4`）が目安です。実行時のメモリ使用量とは異なります。
   - GPU初期化に失敗してCPUへ切り替わる場合はCPU用モデルを追加取得します。旧モデルは自動削除せず、設定画面の文章AIデータ削除でまとめて削除できます。
   - ブラウザでモデルの保存に失敗しても、そのセッションでは推論できます。設定に未保存と表示し、次回の起動では再取得が必要になります。
   - 画像の自動黒塗りはOCR・ルール・写真判定で行います。今回のモデル変更による日本語チャットの黒塗り精度は未測定です。

## 🛠️ 技術スタック

- **フロントエンド**: TypeScript, HTML5 Canvas, Vanilla CSS
- **OCR・文字認識**: Tesseract.js (クライアントサイド WebAssembly)
- **アイコン**: Lucide Icons
- **ビルドツール**: Vite
- **画像の個人情報判定**: 正規表現・辞書・チェックディジット・帳票レイアウト規則
- **任意の文章清書・伏字化**: Transformers.js / ONNX Runtime、Qwen3 0.6B（4bit量子化・思考OFF）

## 🚀 ローカル起動方法

```bash
# 依存パッケージのインストール
npm install

# 開発サーバー起動
npm run dev

# 本番用ビルド
npm run build

# 個人情報ルール・OCR座標・写真検出・再解析の回帰テスト
npm test
```

精度改善の内容、速度の測定条件、実画像での制限は [検出改善レポート](docs/redaction-improvement-2026-10-10.md) にまとめています。
